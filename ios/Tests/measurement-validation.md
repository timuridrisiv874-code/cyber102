# Контроль двухточечного замера на iPhone

## Корпус очистителя воздуха, 355 мм

На семи кадрах одной съёмки iPhone 13 Pro код приложения дал **340,2–345,8 мм**. Во всех семи случаях длина занижена. Средняя абсолютная ошибка **11,6 мм (3,27%)**, максимальная **14,8 мм**. Эталон — высота от основания до верхнего обода, измеренная автором набора рулеткой. Оценка относится к этому корпусу и этим ракурсам. Она включает ошибку выбора концов закруглённого корпуса по изображению. [Michael Fowler, iPhone LiDAR 360° RGB-D Object Scans, версия 21499803, CC BY 4.0](https://doi.org/10.5281/zenodo.21499803)

| Кадр | Расстояние, мм |
|---:|---:|
| 0 | 344,30 |
| 30 | 341,97 |
| 60 | 345,44 |
| 90 | 342,07 |
| 120 | 343,96 |
| 150 | 345,80 |
| 180 | 340,15 |

Изначальная выборка состояла из каждого 30-го кадра от 0 до 240. На кадре 210 обод вышел за границу, на кадре 240 основание закрыто корпусом. В остальных семи отметили передний край верхнего обода и соответствующий край основания по RGB, до просмотра численных результатов. Координаты зафиксированы в скрипте. Каждый конец получил собственную глубину и оценку достоверности из синхронных карт iPhone. Калибровка взята из записи конкретного кадра. Режим офлайн-повтора использует те же функции Swift для фильтрации соседних глубин, восстановления координат и расчёта расстояния, что и экран iPhone. Эталонная высота используется только при подсчёте ошибки. Физический iPhone с этой версией приложения при прогоне не использовался.

## Повторить

Из корня проекта на Mac со Swift. Для первого скрипта нужен Pillow, для второго — OpenCV. Путь к каждому исходному набору указывается явно.

```sh
python3 ios/Tests/replay_iphone_measurement.py /path/to/air_purifier_01.zip
python3 ios/Tests/TUMCheckerboard.py /path/to/rgbd_dataset_freiburg3_checkerboard_large
python3 ios/Tests/check_square_depth_scale.py /path/to/ARDepthLimits-0.4.zip

swiftc ios/Cyber102/MeasurementGeometry.swift ios/Cyber102/PhotoMeasurement.swift ios/Tests/PhotoMeasurementChecks.swift -o /tmp/cyber-photo-check
/tmp/cyber-photo-check
swiftc ios/Cyber102/MeasurementGeometry.swift ios/Cyber102/LidarSampling.swift ios/Tests/LidarSamplingChecks.swift -o /tmp/cyber-depth-check
/tmp/cyber-depth-check
```
