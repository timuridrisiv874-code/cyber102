# Cyber102 для iPhone

Проект для iPhone с iOS 18 и новее. На экране осмотра можно выбрать фотографию или один кадр видео, снять оборудование камерой, считать QR и сохранить текст наблюдения вместе с номером объекта. Небольшая кнопка QR в видоискателе считывает серийный номер или паспортную ссылку. Приложение ищет номер во встроенном каталоге. В видоискателе появляются номер и название найденного объекта; в карточке также видны модель и изготовитель, когда они указаны в каталоге. Неизвестный номер оставляет прежний объект выбранным. Демо-объекты отмечены отдельно. Для видео ползунок выбирает обрабатываемый кадр и его таймкод попадает в запись. Журнал хранит последние десять осмотров на устройстве.

LFM3-VL-2B обрабатывает кадр локально. В установку включены те же два проверенных файла GGUF, что и в полном Android APK. Системный перевод Apple показывает русский текст рядом с английским оригиналом. Для первого использования пары английский–русский iOS может запросить разрешение на загрузку языковых данных. [Описание Translation от Apple](https://developer.apple.com/documentation/translation/translating-text-within-your-app)

## Замер детали

На iPhone с LiDAR нажмите «Снять с LiDAR», зафиксируйте кадр и отметьте два конца детали. Приложение вычислит прямое расстояние между точками по глубине каждой из них. При пропуске глубины, резком перепаде на краю или слишком близких точках результат доступен в пикселях. Для повторного замера есть кнопка «Переснять».

Для снимка из камеры или галереи нажмите «Замер по фото». Изображение можно увеличить двумя пальцами. Если исходный файл содержит дистанцию до объекта и параметры для расчёта масштаба, приложение покажет приблизительную длину в миллиметрах. Такая оценка предполагает плоскую поверхность на дистанции фокусировки, снятую прямо. При недостаточных данных выводится длина в пикселях исходного снимка. Фото с отмеченными точками и способом измерения можно сохранить в журнал без запуска модели.

## Подготовка и сборка

Подготовьте полный репозиторий на Mac с Xcode и iOS SDK, Python 3.12+ и CMake 3.22+ в PATH. Проект использует общий каталог из `mobile/` и исходники движка из `android/`. Из корня репозитория выполните команды ниже.

```sh
python3 tools/prepare_android_models.py --download
bash ios/Engine/build-xcframework.sh
xcodebuild -project ios/Cyber102.xcodeproj -scheme Cyber102 \
  -configuration Debug -destination 'generic/platform=iOS Simulator' build
```

Скрипт использует CMake и закреплённую ревизию llama.cpp. Он создаёт статический модуль для iPhone и для симулятора на Apple Silicon. Для сборки на телефон откройте Cyber102.xcodeproj, выберите команду подписи и подключённый iPhone.

## Проверка

Общий движок на этом Mac обработал реальную фотографию трубы через интерфейс Swift. Swift-компилятор также проверил интерфейс приложения с помощью SDK Mac Catalyst. Нативный интерфейс камеры, распознавание QR и системный перевод требуют проверки на iPhone. На машине разработки установлены Command Line Tools с macOS SDK. Пакет IPA и проверка приложения в iOS Simulator требуют полного Xcode. [Результат проверки движка](Engine/host-verification.json)
