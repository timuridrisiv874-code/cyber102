# Готовые материалы Cyber102

- [Инженерный пакет Word](documents/cyber102-engineering-pack.docx) — редактируемая версия.
- [Инженерный пакет PDF](pdf/cyber102-engineering-pack.pdf) — версия для чтения и передачи.
- [Архив команды](cyber102-research-pack.zip) — документы, JSON-шаблоны и исходники с манифестом SHA-256.

Исходные главы находятся в [docs/research](../docs/research/README.md), команды пересборки — в [tools](../tools/README.md). Правки сначала вносят в исходники и затем пересобирают экспорты, чтобы версии оставались согласованными.

Word и PDF фиксируют инженерный пакет версии 1.1 от 13 ноября 2026 года. Развитие видеорежима и переход на InternVL3 описаны отдельно в [архитектуре камеры](../docs/architecture/vision.md) и [исследовании моделей](../docs/ml/internvl3-research.md); эти дополнения входят в обновлённый ZIP.

Архив версии 1.3 дополнен [каталогом материалов заказчика](../data/customer/README.md), импортированными примерами датчиков и разделом веб-приложения для проверки связок. Оригинальные 58 файлов и JPEG-превью переданы отдельно на сервер команды; они исключены из этого ZIP и Git.

Версия ZIP 1.4 добавляет [паспорта организаторов](../docs/architecture/equipment-passports.md), поиск по документации, режимы каталога внешнего осмотра/ремонта и [воспроизведение телеметрии](../docs/architecture/telemetry-integration.md). PDF-оригиналы организаторов хранятся отдельно на сервере; каталог, происхождение и извлечённые сведения входят в архив. Word/PDF инженерного пакета остаются снимком версии 1.1.
