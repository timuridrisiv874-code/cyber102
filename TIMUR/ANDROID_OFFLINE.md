# Проверка Cyber102 на Android 0.14

Для проверки на телефоне достаточно **полного APK**. Он содержит LFM3 для осмотра фотографии, переводчик Firefox EN→RU и каталог с 16 паспортными объектами и демо-насосом. Сервер, Android Studio и отдельная загрузка весов для этого варианта не требуются.

## Установка

1. На телефоне с Android 8+ и процессором ARM64 войдите в GitHub под учётной записью команды. В разделе **Assets** скачайте **Cyber102-0.14-lfm3-catalog-offline.apk**, 1,52 ГБ. [Тестовый релиз Android 0.14](https://github.com/timuridrisiv874-code/cyber102/releases/tag/android-v0.14-test)
2. Откройте файл, разрешите установку из выбранного источника и запустите Cyber102. Выберите **«Офлайн на телефоне»**. При первом запуске приложение копирует ещё 1,48 ГБ весов в свои данные. Оставьте запас свободного места сверх размера APK и этой копии.
3. Дождитесь сообщения **«Модель готова»**. Теперь можно включить авиарежим. Для перевода используется Android System WebView с поддержкой WebAssembly SIMD. [Установка лёгкой версии и импорт двух GGUF](../android/README.md#полная-и-лёгкая-сборки)

## Проверка осмотра и QR

Откройте тестовый QR на другом экране или распечатайте его. В Cyber102 нажмите **«Включить камеру»**, разрешите доступ и нажмите **QR** в углу видоискателя.

| Какой QR показать | Что должно появиться |
|---|---|
| [Паспортная ссылка насоса](../android/app/src/androidTest/assets/qr-catalog-pump.png) | Насосный агрегат №1, номер `21031004-1` |
| [Неизвестная метка](../android/app/src/androidTest/assets/qr-label.png) | Сообщение, что объект отсутствует в каталоге. Предыдущий насос остаётся выбранным |
| [Серийный номер электродвигателя](../android/app/src/androidTest/assets/qr-catalog-motor.png) | Электродвигатель №1, номер `230201068`, модель BRA160M4 FБУ1 |

Наведите камеру на оборудование или выберите фото и нажмите **«Проверить кадр»**. Сверьте русский текст с фото. При спорном термине раскройте английский оригинал. Добавьте заметку, сохраните осмотр и откройте **«Осмотры на телефоне»**. Проверьте, что с наблюдением сохранился номер выбранного объекта. Время обработки на телефоне видно в карточке отдельно для анализа и перевода. [Протокол проверки на эмуляторе Android 15](../artifacts/android-lfm3-catalog/verification-android15.json)

## Для разработчика

Весь проект собирается из корня репозитория. Android и iPhone используют один файл каталога и общий движок LFM3. Для обновления поверх установленного тестового APK Android требует ту же подпись. Собственный debug-ключ коллеги может отличаться. Удаление приложения для смены подписи очищает локальный журнал.
