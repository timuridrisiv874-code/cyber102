# Тимур — веб-приложение и интеграция

Тимур отвечает за общую вебку для iPhone Safari и Android WebView, API диагностики и журнал осмотров. С участником 3 он согласует адрес приложения, вход и разрешения камеры в Android-оболочке.

Для команды подготовлены [описание продукта](product-guide.md) и [пакет первого чекпоинта](checkpoint-1-speaker-kit.md): шесть слайдов, текст спикера, показ на пять и две минуты, проверка APK и ответы жюри. Редактируемые версии: [руководство Word](../output/documents/cyber102-product-guide.docx) и [сценарий Word](../output/documents/cyber102-checkpoint-1.docx).

[Документ со скриншотами сервиса](../output/documents/cyber102-service-screenshots.docx) — девять страниц с мобильным видом, ответом модели, паспортами, телеметрией, правилами и журналом. К каждому экрану добавлены пояснение и ссылка на стенд. Это снимки первого чекпоинта до обновления 0.5; новые функции перечислены ниже.

На [стенде команды](https://cyber102.94.41.87.102.sslip.io/) доступны демонстрационный паспорт `P-102`, сценарии и журнал. Камера анализирует кадр локальной моделью на сервере. Встроенные примеры на экране камеры используют тестовые ответы. В версии 0.5 кадр привязывается к выбранному серийному номеру, инженер подтверждает признаки и выбирает отсутствие телеметрии либо явно обозначенный демосценарий. Диагноз рассчитывается из этих входов; кадр, ответ модели и снимок показаний сохраняются в историю. Подключение настоящего сервера ввода/вывода остаётся следующим этапом.

## Функциональные изменения 0.5

Краткий профиль модели сохраняет детализацию кадра и возвращает класс и рамку; текст пояснения отмечен как сформированный по классу. Подробный профиль оставлен по умолчанию. В интерфейсе показана задержка ответа на устройстве и сервере. Занятость GPU вызывает до трёх коротких повторов того же кадра, без параллельных запросов.

Показ: открыть камеру → проверить кадр → выбрать `P-102` → явно подтвердить нужный признак → выбрать демотелеметрию → рассчитать выводы → сохранить → открыть историю и исходный кадр. Самостоятельное распознавание точного серийного номера и подтверждённая точность детектора пока не заявляются.
