# Детекторы Cyber102

Цель онлайн-модели — локализовать видимые дефекты на сервере RTX 3090 Ti. Для этого обучается YOLO11m при 768 px. Мобильный пилот YOLO11n обучен отдельно при 416 px. Формат ONNX использует тензор `[1, 3, размер, размер]` и выдаёт прямоугольники до NMS. Порог и постобработка должны пройти проверку на устройстве.

| Источник | Покрытие и этап |
| --- | --- |
| Фото Cyber102 | 29 кадров для обучения, 6 для валидации. Четыре класса — коррозия, следы жидкости, трещина, повреждение клеммы |
| MVTec AD Cable | Загружены PNG и маски. Восемь кабельных классов добавлены в эксперимент онлайн-детектора. Маски преобразованы в прямоугольники. Этот набор опубликован по CC BY-NC-SA 4.0 |
| Коррозия в промышленных комплексах Остравы | Загружены 105 фото с масками. Сохранено авторское разделение train, validation, test. Архив сверён по авторской контрольной сумме |
| PWDID | Архив получен, сверена контрольная сумма. Требуется проверить исходные фото и разметить прямоугольники для фотографий с метками на уровне изображения |
| VIP/PDI | У VIP по ссылке опубликована форма соглашения для получения данных |
| Roboflow Universe | Для выгрузки размеченных архивов через API нужен ключ Roboflow |
| Mendeley Oil Leak | Метка относится ко всему изображению. Для обучения локализации нужны прямоугольники или маски |
| Рентген сварных швов | Требует разметки и отдельной проверки на рентгеновских снимках |
| Hydraulic Components | Метки деталей гидросистемы можно использовать для привязки дефекта к узлу |

Оба пилота прошли экспорт и запуск ONNX на сервере. YOLO11s при пороге 0,25 нашёл коррозию в двух сценах `5.mp4` и дал одну лишнюю отметку коррозии на `2.mp4`. YOLO11n при этом пороге пропустил дефекты на десяти проверочных JPEG. Эти пилоты оставлены для сравнения. Офлайн-прогоны на Redmi отложены по просьбе пользователя.

В первом запуске YOLO11m 153 кадра для обучения, 37 для валидации и 8 контрольных фото. Обучение запущено на 80 эпох с ранней остановкой. Следующий проход продолжает с лучшего checkpoint и добавляет маски коррозии из Остравы.

Карта классов в `ml/defect_detector/classes.json` отражает целевое покрытие. Конкретный набор классов для обучения берётся из проверенной разметки. Пустые значения в отчёте покрытия означают, что на класс пока нет примеров. Результаты на независимых сценах должны храниться отдельно от метрик обучающей выборки.

## Сравнение моделей описания

Qwen3.5-2B и LFM3-VL-2B проверены на семи JPEG из приложения. Оба использовали модель Q4_K_M и проектор Q8. В прогоне с CUDA-энкодером и CPU-декодером медиана LFM составила 1,08 с, Qwen 1,99 с. LFM в этом прогоне ответил `clear` на трёх чистых кадрах, Qwen дал ложные признаки на двух. На сложных кадрах LFM иногда перечислял лишние дефекты. В отдельном CPU-прогоне с более короткой инструкцией обе модели ошибочно указали трещину на всех трёх контрольных кадрах. Медиана на CPU составила 3,36 с для LFM и 5,26 с для Qwen. Задержка измерена на сервере, качество чувствительно к формулировке инструкции.

MiniCPM-V 4.7 1B с обученной головой и исходным проектором заметил разрыв на двух JPEG из `2.mp4` и разделил трещину и ржавчину на контрольных JPEG из `5.mp4` при серверном тесте. Исходный генеративный MiniCPM обработал один кадр на Redmi за 109,3 с. Отдельный замер головы на Redmi прерван при отключении USB для зарядки Mac. На сервере подготовлен более компактный ускоренный проектор Q8. Его качество на мелком разрыве зависит от разрешения кадра.

## Цикл оценки онлайн-детектора

RGB-прогон YOLO11m v3 с 75 дополнительными кадрами коррозии достиг mAP50 0,265 на смешанной валидации. На десяти отложенных кадрах Cyber102 при пороге 0,25 и IoU 0,50 он пропустил четыре трещины, три повреждения клеммы и две рамки коррозии. На двух из трёх чистых кадров есть ложные отметки. У YOLO11s при таких же настройках совпала одна рамка коррозии, при этом на дефектных сценах остались 36 лишних или плохо локализованных рамок. Результаты получены на малой выборке с повторяющимися сценами. Несколько кадров одной сцены не дают статистики по независимым агрегатам.

YOLO11m v4 обучается на 1101 кадре. Добавлены 650 кадров трещин Steelcrack, вручную размеченные исходные панели 17 фотографий PWDID и 210 композиций для редких признаков из доноров только обучающей выборки. Для валидации выделено 155 кадров, для проверки из исходных датасетов — 104. Видео Cyber102 и фотографии контрольных узлов держатся вне обучения. Дополнительно подготовлены пять кадров из `3.mp4` и `4.mp4` для проверки переноса. Оценка с полным кадром и перекрывающимися кропами записывает точные попадания при IoU 0,30 и 0,50, ложные тревоги, пропуски и длительность обработки.

Рентгеновский YOLO11m поставлен после RGB-прогона. Из авторского набора SteelTube подготовлено 807 обучающих, 269 валидационных и 278 тестовых снимков. Варианты одной исходной фотографии и копии с совпадающим SHA-256 отнесены к одной выборке. Для подреза сварного шва в архиве удалось выделить только одну исходную группу, поэтому независимая оценка этого класса ещё требует данных. На тестовой части также отсутствует положительная разметка шлаковых включений.
