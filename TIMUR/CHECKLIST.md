# Проверка вебки и API

## На ноутбуке

Запустите из корня репозитория в первом терминале.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m server.app
```

Из корня во втором терминале выполните проверки.

```sh
curl -fsS 'http://127.0.0.1:8000/api/health'
curl -fsS 'http://127.0.0.1:8000/api/diagnose?serial=P-102&scenario=multiple_findings'
curl -fsS 'http://127.0.0.1:8000/api/history?serial=P-102'
.venv/bin/python -W error -m unittest discover -s tests -v
```

- [ ] `/api/health` вернул `status: ok`. Сценарий вернул выводы об утечке, защитном кожухе, смазке или износе подшипника и регламентном ТО. Тесты прошли.
- [ ] В [локальном интерфейсе](http://127.0.0.1:8000/) сохранён результат сценария с заметкой. После обновления страницы запись отображается в журнале.

## Пройденная автопроверка браузеров

В Chromium и мобильном профиле WebKit прошёл браузерный тест с синтетической камерой и тестовым ответом API. Он проверяет отправку JPEG, один запрос в работе, рамку на последнем проверенном кадре, отмену при остановке и уходе со страницы. [Команда запуска](../tests/browser/README.md).

Отдельно прошёл реальный HTTPS/GPU-прогон InternVL3 с синтетическим потоком камеры в Chromium и WebKit. [Протокол](../docs/ml/internvl3-browser-report.json). Он подтверждает связку браузер → сервер → модель; разрешения физической камеры проверяются ниже.

## На физических телефонах

Откройте [камеру на удалённом HTTPS-стенде](https://cyber102.94.41.87.102.sslip.io/index.html) на iPhone в Safari и на Android в WebView. Для демонстрации используйте доступное подключение к интернету. Локальную сеть на площадке настроим отдельно. На стенде кадры обрабатывает InternVL3 на сервере команды. Для паспорта и журнала откройте [диагностику насоса](https://cyber102.94.41.87.102.sslip.io/checkpoint.html?serial=P-102).

## Материалы заказчика

На ноутбуке или телефоне откройте [новый раздел](https://cyber102.94.41.87.102.sslip.io/materials.html). Выберите фотографию и нажмите «Проверить фото». В разделе измерений выберите канал, проверьте график, исходные метки и пороги. В «Проверке связок» раскройте наблюдения, укажите нарушение кожуха и проверьте независимое предупреждение. Затем проверьте сочетание роста вибрации и температуры с нормальным током. Неизвестные входы оставляйте пустыми.

Фото и таблицы предоставлены как примеры; общий серийный номер не подтверждён. Автопривязка фото к строкам Excel отключена. У 18 строк по ВЧ-каналу исходная тревога не подтверждается описанным порогом — расхождение показано отдельно.
