# VisionPsy в Cyber102 0.11

На RTX 3090 Ti обучены четыре независимых линейных классификатора по выходным токенам замороженного визуального энкодера VisionPsy Nano. Офлайн-режим делает один проход энкодера по кадру до 512 px. В APK добавлено 30 КБ коэффициентов. Для вывода наблюдений используется короткий словарь терминов на русском языке.

Для финальных кандидатов использованы 45 исходных фотографий, 180 вариантов с изменением освещения, цвета и масштаба и 60 композиций с уменьшенными участками дефектов. Один кадр с коррозией исключён из обучения из-за сходства со сценой в `5.mp4`. Проверочные видео в обучение не включались. Пороги и варианты головы подбирались по небольшому контрольному набору с ручной сверкой кадров. Чтобы измерить обобщение, нужен новый набор с независимыми сценами. Разные кадры одного видео не считаются независимыми примерами.

## Тест Redmi 2606FRN72Y

Обработка на телефоне в авиарежиме с отключённым Wi‑Fi. Время инференса включает чтение JPEG, подготовку изображения, кодирование и выдачу результата. Готовность модели проверялась перед замером.

| 2.mp4, 4,5 с | Неоднозначно. Повреждения пропущены | 4,73 с |

Медиана по десяти кадрам — 4,68 с. На трёх общих с 0.10 таймкодах, 2.mp4 в 4,5 с, 5.mp4 в 1,5 с и 12,5 с, медиана снизилась с 6,00 до 4,67 с. Отдельная проверка отмены и повторного запуска прошла. На тестовом кадре кнопка вернула управление через 31 мс. Два инструментальных теста прошли на каждом кадре. Chromium и WebKit прошли браузерный тест офлайн-страницы.

В отчёте 0.10 таймкод 12,5 с в 5.mp4 ошибочно назывался разрывом. На скриншоте с этого таймкода видна корродированная задвижка. Крупный разрыв тестировался на 8,5 и 18,5 с.

Сборка Gradle и lint выполнены на сборочном сервере. SHA-256 исходных сборок.

- Полный APK `8e022f88441a220f46ce0e7ad04fc8ae427e066a3fcb2006d6174e203013fb03`
- Лёгкий APK `3b5f7ab17a0bfbddd48f4b182d7cf3397248be25c82f67bc3cb6fe7466d70f0b`

На Redmi полная сборка обновлена прежним тестовым ключом через `adb install -r`. Исходные изображения, видео и ключи установки отсутствуют в Git.
