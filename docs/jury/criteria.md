# Критерии оценки Cyber102

[К README](../../README.md) · [Исходная шкала, часть 1](sources/1000207237.jpg) · [Исходная шкала, часть 2](sources/1000207238.jpg)

**Максимум по шкале — 21 балл.** Семь критериев оцениваются от 0 до 3 баллов. Формулировки уровней перенесены с двух исходных скриншотов.

| Критерий | 0 баллов | 1 балл | 2 балла | 3 балла |
| --- | --- | --- | --- | --- |
| **Прототип** | Нет прототипа | Есть прототип, и частично реализован функционал | Реализована большая часть заявленного функционала | Прототип полностью реализован |
| **Решение основной проблемы** | Нет решения | Решение частично помогает справиться с основной проблемой, заявленной в кейсе | Решает большую часть проблемы | Решает проблему исчерпывающе |
| **Разработка и внедрение** | Разработка не принесёт никакого положительного эффекта | Издержки на разработку и внедрение не оправдывают получаемый эффект | Издержки на разработку и внедрение соответствуют планируемому эффекту | Эффект значительно превышает издержки на разработку и внедрение |
| **Новаторские идеи** | Нет новизны подхода, нет новаторских предложений | Копия существующих решений с одной новаторской идеей | Частичная копия существующих решений с несколькими новаторскими идеями | Абсолютно новый подход, есть уникальные killer-фичи |
| **UI/UX** | Взаимодействие с программой невозможно | Без разработчика целевой пользователь не сможет понять и использовать разработанное решение | Решение может быть использовано продвинутым целевым пользователем | Приложение готово к использованию любым целевым пользователем |
| **Второстепенные проблемы** | Не решает | Решает малую часть второстепенных проблем | Решает большую часть второстепенных проблем | Решает все заявленные проблемы, а также часть потенциальных и перспективных проблем |
| **Аналитика** | Анализ отсутствует | Проведён анализ только целевой и потенциальной аудиторий | Проведён анализ только целевой и потенциальной аудиторий, а также анализ схожих решений | Проведён полноценный анализ целевой и потенциальной аудиторий, проведён анализ схожих решений и проблем пользовательского опыта |
