# Реестр первичных источников

Проверено 58 записей источников на 13 ноября 2026 года. Отдельные записи относятся к одному URL, если документ используется в разных разделах. Реестр содержит 56 уникальных основных адресов. Факт доступности и лицензия набора данных указаны отдельно. Публичный просмотр документа не означает разрешения перепубликовать его целиком.

В JSON-реестрах сохранены утверждения, которые поддерживает источник, ограничения применимости и дополнительные ссылки. Полные тексты сторонних руководств в пакет не включены. При использовании стандартов ISO изучена открытая карточка стандарта; её нельзя выдавать за прочитанный нормативный текст.
