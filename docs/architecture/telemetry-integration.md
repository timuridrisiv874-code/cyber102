# Воспроизведение телеметрии и подключение сервера ввода и вывода

Для чекпоинта локальный сервер Cyber102 воспроизводит 500 строк из двух предоставленных Excel-книг. Для пилота источником измерений станет согласованный сервер ввода и вывода с интерфейсом OPC UA или Modbus. В обоих случаях данные должны сохранять происхождение, единицы, время и качество до расчёта признаков. [Импорт Excel](../../data_tools/import_customer_sensors.py) · [Модуль воспроизведения](../../server/telemetry.py)

## Воспроизведение для чекпоинта

`GET /api/telemetry/catalog` возвращает диапазон индексов, сводку, происхождение, единицы и уставки из описания примера. `GET /api/telemetry/snapshot?index=N` возвращает одну строку по индексу от `0` до `499`. Клиент задаёт интервал воспроизведения, приостанавливает его и выбирает позицию. Сервер не хранит курсор и не меняет строку между одинаковыми запросами. `emittedAt` обновляется при выдаче каждого ответа.

| Поле | Смысл |
| --- | --- |
| `source` | `customer_replay`. Данные воспроизводятся из подготовленной копии. |
| `equipmentSerial` | `null`. Привязка к экземпляру насоса отсутствует. |
| `datasetId`, `index`, `rowCount` | Идентификатор набора и позиция строки. |
| `sourceTimestamp`, `sourceTimezone` | Время из Excel с `sourceTimezone: null`. Исходное время нельзя считать UTC. |
| `emittedAt` | Текущее время выдачи сервером в UTC. При показе следует обозначать его отдельно от исходного. |
| `row` | Исходная строка с числами, метками Excel, расчётами импорта и координатами листа. |
| `quality` | Режим `replay`, неподтверждённое качество полевого измерения `unknown`, недоступные поля диагностики и отсутствующие измерения строки. |

В сводке остаются 18 расхождений между метками Excel и расчётом по описанным уставкам. Оценка общего СКЗ равна `unknown` во всех строках, поскольку числовая уставка для этого канала не предоставлена. Значение СКЗ при этом остаётся доступным. Уровни из `row.assessments` показывают сравнение значения с уставкой примера. Из одного превышения не следует устойчивый перегрев, рост вибрации или подтверждённая неисправность. В файлах отсутствуют ток, давление, КПД, наработка, звук и локальная температура клемм. Уставки импорта и демонстрационный профиль P‑102 ведутся отдельно. [Карта диагностических правил](customer-rule-mapping.md)

## Контракт промышленного адаптера

Адаптер работает на сервере площадки и только читает утверждённые каналы. Каждое измерение передаётся в форме `serial`, `sensor_id`, `component_id`, `quantity`, `unit`, `value`, `source_timestamp`, `received_at`, `quality` и `source`. Сохраняют ссылку на конфигурацию канала и исходный статус протокола. Для агрегированных измерений дополнительно нужны границы окна и фактическая полнота данных. После проверки единиц, актуальности, режима и базового интервала отдельный слой вычисляет признаки для 12 правил. [Схема измерения](../research/schemas/telemetry-schema.json) · [Контракт интеграции](../research/chapters/integration-contract.md)

| Источник | Что нужно согласовать перед подключением |
| --- | --- |
| OPC UA | Адрес и режим безопасности, сертификаты и права чтения, Namespace URI и NodeId, единицы и частота. Сохраняются `DataValue.StatusCode`, `SourceTimestamp` и `ServerTimestamp`, когда они доступны. `received_at` фиксируется при приёме нашим сервисом. |
| Modbus | Адрес сервера ввода и вывода, Unit ID, функции чтения и карта регистров, типы и порядок слов, масштаб и смещение, единицы, период опроса и коды ошибок. Метку источника используют, если она документирована в карте данных. При её отсутствии отмечают время приёма отдельно. |

Для каждого канала нужен согласованный срок актуальности. Плохое качество, неопределённый статус, разрыв связи и просроченное измерение исключают из подтверждения правила и показывают с причиной. При восстановлении связи нужен новый валидный отсчёт. Кадр сопоставляют по подтверждённому `serial`, времени и допустимому расхождению часов. Протокол чтения, список каналов и доступ к серверу определяет площадка. До получения этих параметров прототип работает в режиме воспроизведения. [OPC Foundation DataValue](https://reference.opcfoundation.org/specs/OPC-10000-4/7.11) · [Спецификации Modbus Organization](https://www.modbus.org/modbus-specifications)
