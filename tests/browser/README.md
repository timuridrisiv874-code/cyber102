# Браузерная проверка видеорежима

Из корня репозитория выполните команду в окружении с Node.js 18+, Playwright, Chromium и WebKit.

```sh
node tests/browser/video-smoke.cjs
```

Для уже установленного рантайма можно задать абсолютный путь к модулю в `PLAYWRIGHT_MODULE`, каталог браузеров в `PLAYWRIGHT_BROWSERS_PATH` и путь к системному Chrome в `CHROME_PATH`. Для сохранения PNG укажите каталог в `VIDEO_SMOKE_SCREENSHOTS`.

Тест использует синтетическую камеру и имитирует ответы `/analyze` на локальном HTTP-сервере. В Chromium и мобильном профиле WebKit он проверяет отправку JPEG, последовательность запросов при задержке ответа, рамку на проверенном кадре, отмену при остановке и уходе со страницы, одиночный кадр и обработку ошибки. Для проверки камеры телефона и модели на GPU нужен отдельный прогон.

## Проверка действующего GPU-стенда

`node tests/browser/live-video.cjs` отправляет синтетические кадры на настоящий `/analyze` выбранного HTTPS-стенда. Веса должны быть запущены заранее; тест проверяет InternVL3-2B-hf. Учётные данные читает из игнорируемого `var/deploy-access.json` (`url`, `username`, `password`) или файла в `CYBER102_ACCESS_FILE`, передаёт заголовок входа только выбранному origin. Используются те же `PLAYWRIGHT_MODULE`, `PLAYWRIGHT_BROWSERS_PATH`, `CHROME_PATH`, `VIDEO_SMOKE_SCREENSHOTS`. Результат сохраняется в `var/internvl-browser-report.json`; секреты в отчёт не входят. Камера синтетическая, модель и HTTPS настоящие. Скрипт требует сетевого доступа и не входит в обычный набор unit-тестов.
